# Fabio7X

> Projetos mobile-first, Android, web e ferramentas em português.

Sou Fabio, criador de projetos práticos para celular: ferramentas locais, experiências web, documentação acessível e estudos de segurança defensiva. Meu foco é construir coisas claras, testáveis e honestas sobre o que fazem.

## Em foco

- Aplicativos Android e automação local com privacidade
- Sites e experiências web que funcionam bem no celular
- IA aplicada a organização, protótipos e criação
- Segurança defensiva em ambientes autorizados

## Princípios

- **Mobile-first:** feito para usar bem sem PC.
- **Clareza:** interface e documentação sem enrolação.
- **Privacidade:** dados e permissões só quando necessários.
- **Segurança responsável:** estudos e testes somente com autorização.
- **Evolução real:** testar, corrigir e melhorar em cada versão.
