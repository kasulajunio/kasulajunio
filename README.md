## Sobre mim

Sou Fabio, criador da marca **Fabio7X**. Transformo ideias em produtos digitais: sites, landing pages, experiências interativas e jogos para navegador. Meu foco é combinar uma apresentação visual forte com projetos simples de acessar, rápidos de testar e fáceis de entender.

> **Minha proposta:** se pode ser digital, eu construo.
